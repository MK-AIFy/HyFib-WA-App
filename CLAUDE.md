Project Rule #1

Never rewrite working code.

Project Rule #2

Always audit before coding.

Project Rule #3

Never modify more than one module in one iteration.

Project Rule #4

Always validate after changes.

Project Rule #5

Fix root causes instead of symptoms.

Project Rule #6

Prefer dependency injection.

Project Rule #7

Maintain backward compatibility.

Project Rule #8

Always update tests with code changes.

Project Rule #9

Never exceed context window; summarize completed work before proceeding.

Project Rule #10

Do not mark a task complete until:
- Build passes
- Lint passes
- Type checks pass
- Tests pass
- No security regressions
- No validation gaps
- Logging is present
- Error handling is standardized
